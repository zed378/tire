# Docker Build Checklist

## Files Required for Production Seeding

Ensure these files exist before building Docker image:

### ✅ Prisma Files (REQUIRED)
- `apps/api/prisma/schema.prisma` - Database schema
- `apps/api/prisma/prisma.config.ts` - Prisma configuration
- `apps/api/prisma/migrations/` - All migration files
- `apps/api/prisma/seed/` - Seed data scripts

### ✅ Seed Scripts (REQUIRED)
- `apps/api/prisma/seed.ts` - Main seed orchestration
- `apps/api/prisma/seed-prod.ts` - Production seed wrapper
- `apps/api/src/scripts/seed-prod-admin.ts` - Admin creation script
- `apps/api/src/scripts/seed-csv-prod.ts` - CSV seeding script

### ✅ CSV Files (OPTIONAL - for tire brands/patterns)
- `requirements/req-TB Brand Pattern.csv` - TB tire brands and patterns
- `requirements/req-LT Brand Pattern.csv` - LT tire brands and patterns
- `requirements/req-Size.csv` - Tire sizes
- `requirements/req-Vehicle Brand.csv` - Vehicle brands

### ✅ Build Artifacts (AUTO-GENERATED)
- `apps/api/dist/` - Compiled API code (generated by `pnpm build`)
- `apps/web/dist/` - Built SPA (generated by `pnpm build`)
- `packages/contracts/dist/` - Contract types (generated by `pnpm build`)

## Build Process

### Pre-Build Verification

```bash
# Verify Prisma files exist
ls -la apps/api/prisma/schema.prisma
ls -la apps/api/prisma/migrations/

# Verify seed scripts exist
ls -la apps/api/prisma/seed*.ts
ls -la apps/api/src/scripts/seed-*.ts

# Verify CSV files (optional)
ls -la requirements/
```

### Build Command

```bash
# Build all packages and Docker image
pnpm build
docker build -t commercial2026:latest .

# Or specify Dockerfile explicitly
docker build -f Dockerfile -t commercial2026:latest .
```

### Dockerfile Stages

1. **base** - Alpine Node.js 24
2. **deps** - Install dependencies
3. **build** - Build all packages
4. **api** - Final production image with:
   - Compiled dist/ directories
   - Prisma schema and migrations
   - Seed scripts
   - Requirements CSV files
   - Web SPA
   - Uploads directory

## Docker Image Contents

## Deployment Verification

### 1. Run Migrations

```bash
docker run -e DATABASE_URL="postgresql://..." commercial2026:latest \
  pnpm db:migrate
```

### 2. Create Admin Account

```bash
docker run -e DATABASE_URL="postgresql://..." commercial2026:latest \
```

### 3. Seed Master Data

```bash
docker run -e DATABASE_URL="postgresql://..." commercial2026:latest \
  node dist/scripts/seed-csv-prod.js
```

### 4. Verify Seeding

```bash
docker run -e DATABASE_URL="postgresql://..." commercial2026:latest \
  node -e "
    const { PrismaClient } = require('@prisma/client');
    const p = new PrismaClient();
    Promise.all([
      p.province.count(),
      p.city.count(),
      p.vehicleBrand.count(),
      p.tireBrand.count()
    ]).then(([prov, city, vb, tb]) => {
      console.log(\`Provinces: \${prov}, Cities: \${city}, Vehicle Brands: \${vb}, Tire Brands: \${tb}\`);
      process.exit(0);
    });
  "
```

## Troubleshooting Build Issues

### Missing Prisma schema

**Error**: `Could not find Prisma Schema`

**Solution**: Ensure Dockerfile copies schema:
```dockerfile
COPY --from=build /app/apps/api/prisma ./prisma
```

### Missing migrations

**Error**: `No migration files found`

**Solution**: Ensure migrations directory is copied:
```dockerfile
COPY --from=build /app/apps/api/prisma ./prisma
```

### Missing seed scripts

**Error**: `Cannot find module seed-prod-admin.js`

**Solution**: Ensure scripts are built and included:
```dockerfile
# In build stage
RUN pnpm --filter @c26/api build

# In final stage
COPY --from=build /app/apps/api/dist ./dist
```

### CSV files not found

**Error**: `ENOENT: no such file or directory, open 'requirements/req-TB Brand Pattern.csv'`

**Solution**: Copy requirements directory (optional but recommended):
```dockerfile
COPY requirements/ ./requirements/ 2>/dev/null || true
```

The `2>/dev/null || true` makes it optional - build won't fail if directory doesn't exist.
